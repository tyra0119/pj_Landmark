# MVP：スカイツリー×月

公開URL：https://tyra0119.github.io/pj_Landmark/

## できること

- **日付から探す**：その日に月（または太陽）がスカイツリーの先端に重なって見える地上の場所を、時刻つきの線で地図に表示
  - 線の明るい部分＝建物に遮られず先端が見える場所。リストに時刻・場所（町丁目）・距離・幅・秒数・焦点距離の目安
  - 次の満月6回をワンタップで選べる
  - 重ね方：「先端を中心に」（月の中心が先端）／「先端に乗せる」（月の下端が先端）
- **地点から探す**：地図をタップ（または現在地）すると、その地点から重なる日時を1年分計算。輝面比と空の明るさも表示
- **見え方マップ**：半径8kmで、スカイツリーがどこからどれだけ見えるかを色分け
- 日付・天体・重ね方はURLに残るので、そのまま共有できる

## 仕組み

1. PLATEAUのCityGML（342ファイル・約21.5GB）からLOD1の建物だけ抜き出す（約68万棟、区境の重複を除去）
2. 地理院の標高＋建物の高さで地表モデルを作る（約1.94mメッシュ）
3. スカイツリーの高さ7段階を視点に放射状のレイで可視判定（地球の丸みと大気差を補正）→ 地図タイル化
4. ブラウザで Astronomy Engine により月・太陽の方位と高度を15秒ごとに計算し、先端と同じ仰角になる距離を逆算。線上を2m間隔でタイルから可視判定

詳細：`pipeline/README.md`

## 確認できたこと

- 2026/10/26（満月）の夕方17:22、**聖橋（御茶ノ水駅）付近**が重なる場所として出た。聖橋は実際にスカイツリーが見える場所として知られている
- 同日朝4:51、**荒川河川敷**で約830mにわたって沈む月が重なる。河川敷も定番の撮影地
- 計算時間：パイプライン約30秒（データ取得は別に十数分）、ブラウザでの1日分の計算は1秒前後

## 制約・今後

- 街路樹・電線・高架道路（首都高など）・データ作成後の新しい建物は未反映
- 川の上など立ち入れない場所も候補に含まれる → 水域・道路データで絞り込みたい
- 橋の上は地面の高さで計算しているため、実際より数m低い
- 半径8kmより遠くは対象外
- 次の候補：東京タワー・富士山への展開、複数ランドマークの同時可視、ARプレビュー
