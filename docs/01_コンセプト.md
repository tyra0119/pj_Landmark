# コンセプト

アプリ名：**ランドマーク × 月/太陽 撮影スポット案内**

Project PLATEAU の3D都市モデルを使い、ランドマークが**地上から**見える場所を提案するアプリ。

## 対象ランドマーク

- 富士山（実装済み：都心から）
- 東京スカイツリー（実装済み）
- 東京タワー（実装済み）
- 花火大会（後回し。理由は [02_類似サービス調査](02_類似サービス調査.md)）

## 狙い（差別化の軸）

> 「○月○日○時、月や太陽がランドマークにちょうど重なり、しかも建物に遮られない地上の場所」を地図上で探せる。

類似サービス調査で、この機能をしているものは見つからなかった。

## 差別化できる機能の例

- **天体との重なり**: 満月×スカイツリー、ダイヤモンド富士／パール富士を建物込みで計算
- **写り方の情報**: 見かけの大きさ（角度）と、それに合うレンズの焦点距離
- **複数ランドマークの同時可視**: 「富士山とスカイツリーが同時に見える場所」
- **現在地から近い順の提案**と、ARでの見え方プレビュー

## 技術メモ

- 可視判定は向きを逆にする：ランドマーク頂上から全方向の深度マップ（キューブマップ）を描き、地上点までの距離と比較（シャドウマップと同じ発想）
- 「見える／見えない」ではなく、ランドマーク側を高さ方向にサンプリングして**見え度**を出す
- 精度を下げる要因：街路樹、高架、データ作成後の新築、LOD1の誤差、遠距離での地球の丸み・大気屈折
- 建物の中や私有地を除き、道路・公園・歩道橋など人が立てる場所に絞る
