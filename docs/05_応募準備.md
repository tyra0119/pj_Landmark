# 応募準備：公共交通オープンデータチャレンジ2026

- 応募条件：https://challenge2026.odpt.org/ja/entry.html
- 開催概要：https://challenge2026.odpt.org/ja/outline.html
- 主催：公共交通オープンデータ協議会、国土交通省

## 応募の必須条件（要点）

- **公共交通のオープンデータを使うこと**（公共交通オープンデータセンターのデータ、または主催者が公開する鉄道・バス・航空・フェリー・シェアサイクル等のデータ）← **今のアプリは未対応**
- チャレンジ期間中、誰でも無償で使える状態で公開（日本国内で使えればよい）
- API利用規約・ガイドライン、各データのライセンスを守る。データの第三者提供・目的外利用は禁止
- 主催者が作ったように見せない。問い合わせ先を記載
- 他のコンテストに出した作品も応募可（各規約の確認は必要）
- 締切までは更新可。締切後はバグ修正程度。説明文は提出後に編集不可

## 審査で重視される点

社会課題解決への寄与／オープンデータ活用のインパクト／技術的な完成度／UI・UXの完成度

## 応募の手順（ユーザー本人が行うもの）

1. 公共交通オープンデータセンター開発者サイト（https://developer.odpt.org/）でユーザー登録（確認に最大2営業日）
2. 開発者サイトからチャレンジにエントリーし、アクセストークンを取得
3. 専用サイトの応募フォームから作品を応募

## 使えそうな交通データ

- 東京都交通局（都営地下鉄・都営バス・都電・日暮里舎人ライナー）：駅・時刻表・運行情報・位置情報。CC BY 4.0
- 東京メトロ：駅・時刻表・運行情報など。公共交通オープンデータ基本ライセンス
- JR東日本：GTFS時刻表、GTFS-RT列車位置、運行情報
- ゆりかもめ、ほか関東の事業者
- シェアサイクル：ドコモ・バイクシェア、ハローサイクリング（GBFS、ポートの空き台数）
- GTFSデータリポジトリ（https://gtfs-data.jp/）：市町村や民間のバス（富士山周辺の路線バスも要確認）

## アプリに足す機能の案（公共交通との結びつき）

1. **最寄り駅・バス停と徒歩時間**：各撮影スポットに表示
2. **間に合う電車と帰りの終電／行きの始発**：月の出・月の入りは夜や早朝が多いので、「始発前」「終電後」を明示
3. **シェアサイクル**：電車が動いていない時間帯の代わりに、スポット近くのポートと空き台数
4. **当日の運行情報**：遅延・運休
5. **富士山周辺のバス**：田貫湖・朝霧高原へのバス時刻

社会課題との関係：定番の撮影地への集中を分散させる、車を使わない撮影行（公共交通の利用促進）、夜間・早朝の移動を事前に計画できる

## 実装状況（2026-10-03）

- 交通データの取得は `iss` と同じ方式：アクセストークンは中継サーバー（https://tyra.jp/odpt/api/）に置き、ブラウザには出さない。中継は `https://tyra0119.github.io` からのアクセスを許可
- **済**：最寄り駅（2km以内・2駅）と徒歩時間、その時刻に電車で行けるか（始発前／帰りの終電後、平日・土休日ダイヤ）、当日の運行情報、電車が動いていない時間だけ、近くのシェアサイクル（500m以内）。始発前は返却できる空き、終電後は借りられる台数
  - 駅・始発終電は `iss` が ODPT から作った data/transit.json から観測範囲周辺の689駅を抽出（`pipeline/make_transit.py`）
  - シェアサイクルはドコモ・バイクシェア、ハローサイクリングのGBFS（約4,800ポート）
- 富士山周辺（田貫湖・御殿場）は ODPT の駅データがなく「範囲外」と表示 → GTFSデータリポジトリのバスを要調査

## 富士山周辺のバスの調査結果（2026-10-03）

- GTFSデータリポジトリ（静岡県12件）にも ODPT にも、富士急系・富士宮市・御殿場市のバスは**なし**
- 富士急が自社サイトでGTFS-JPを公開（APIキー不要、ライセンス表記なし。https://bus.fujikyu.co.jp/rosen/gtfs/ ）
  - 富士急モビリティ（御殿場・小山地区）：https://gtfs-jp.buskita.com/fmo/gtfs.zip 。御殿場圏の停留所329（御殿場駅・富士岡駅・足柄駅など）。有効 〜2026-12-31
  - 富士急バス：https://gtfs-jp.buskita.com/fjb/gtfs.zip 。田貫湖圏21（道の駅朝霧高原・朝霧高原・猪の頭入口・白糸の滝入口など）、御殿場圏24。有効 〜2026-12-31
- **田貫湖・休暇村富士へ行く富士急静岡バス「北山線」はデータなし**。宮バス・箱根方面のバス・JR御殿場線/身延線もなし
- 小山町のGTFSは期限切れ（同じ路線は富士急モビリティに含まれる）
- 群馬バス（ODPT、CC BY 4.0）の高速「御殿場・沼津・八王子号」は使える可能性あり（未検証）
- 注意：応募条件の「ODPT／GTFSデータリポジトリのデータ」には富士急データは含まれない → 条件は都心のODPTデータで満たし、富士急は補助に。早朝便が少なく、日の出のダイヤモンド富士にはバスで間に合わないことが多い

## 公開版での確認（2026-10-03）

- 運行情報・シェアサイクルの台数は公開サイト（tyra0119.github.io）から中継経由で取得できた。手元（localhost）では中継の許可対象外なので表示されない
- 例：浅草駅付近 → 銀座線「一部の列車に遅れが出ています。」を遅れと判定、他線は平常。浅草駅前のポート「いま貸出7台・返却10台」
